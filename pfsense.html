Pare-feu pfSense

pfSense, un pare-feu open source, a été installé dans une machine virtuelle VMware pour séparer et protéger trois réseaux : Internet (WAN), le réseau interne (LAN) et un réseau annexe (OPT1).

Objectif

pfSense est un pare-feu open source basé sur le système FreeBSD. Il filtre le trafic avec un pare-feu à états (Packet Filter) et assure aussi le routage et le NAT, ce qui lui permet de relier plusieurs réseaux. C'est l'équivalent libre des routeurs professionnels propriétaires, adapté à la sécurisation d'un réseau d'entreprise.

Installation

  1. Télécharger pfSense : l'image ISO de pfSense CE 2.6.0 est récupérée sur le site officiel.
  2. Vérifier l'intégrité du fichier : on calcule l'empreinte SHA256 du fichier téléchargé et on la compare à celle publiée. Si les deux sont identiques, le fichier n'a pas été altéré.
  3. Créer la machine virtuelle dans VMware : l'ISO est décompressée puis sélectionnée, la machine se nomme pfsense, avec un disque de 20 Go (valeur par défaut), 1 Go de mémoire et les trois cartes réseau.
  4. Lancer l'installation, puis redémarrer pour arriver au menu de pfSense.

Deux constats après le redémarrage :

  • Seules deux interfaces sont reconnues à ce stade (em0 et em1).
  • Le clavier est en qwerty malgré le choix du français pendant l'installation. Le passage au français depuis le shell (option 8 du menu) ne dure que jusqu'au prochain redémarrage. Le réglage définitif se fait ensuite depuis l'interface web.

Configuration des interfaces

La configuration se fait depuis le menu de pfSense en deux temps.

  1. Déclarer les interfaces (option 1 du menu) : on désigne laquelle sert de WAN, de LAN et d'OPT1.
  2. Attribuer les adresses IP (option 2 du menu) :

Pour le WAN, les adresses dépendent de la box Internet. Une commande ipconfig /all sur la machine physique donne le réseau (192.168.1.0/24) ainsi que la passerelle et le DNS (192.168.1.1).
